4) What is the process of testing to make sure the SPA is working with the API to GET and PUT data in the database?
  
  In order to test to make sure that the GET and PUT functionality within the code is working correctly so that it can be added or updated within the database we used the POSTMAN application.  Using the POSTMAN application we applied the GET and PUT functionalities to their specified URL locations.  When this is done using GET(Read in CRUD) it allows us to see the webpage through POSTMAN meaning that the URL is connecting properly.  When this is done using the PUT functionality, for both the ability to add or update a trip(Create or Update in CRUD), it allows you to either add or update a Trip in the database successfully.  We then check the database using MongoDB compass to make sure that the conversion was successful.
