# CS-465 – Full Stack Web Application

A full stack web application developed as part of **CS-465: Full Stack Development I**.  
This project demonstrates frontend and backend integration, RESTful API development, authentication concepts, and database persistence using a modern web stack.

---

## 🛠 Tech Stack

**Frontend**
- Angular (Single Page Application)
- HTML5 / CSS3
- JavaScript / TypeScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB (NoSQL)

---

## ✨ Features

- Single Page Application (SPA) architecture
- RESTful API built with Express.js
- MongoDB database for data persistence
- Authentication and authorization concepts
- Secure access to protected routes
- Dynamic client-side rendering without full page reloads
