# CS-465-Full-Stack-Development-I

1) You have wired the database to the frontend and have a working RESTful API. Describe how Postman is used to facilitate development. Are there other tools that could also be used?

   Postman is used to verify that the operations of CRUD(Create, Read, Read All, Update and Delete) are functional.  It makes sure that, as long as a website URL has any of the above stated operations, you can apply them through postman officially or as test to see if the operation works.  Another too that I used in conjunction to Postman was MongoDB compass to properly be able to delete files that I added to the database because the delete operation was not required for this course.  Through MongoDB Compass you could also view the database contents to make sure that your database has the correct information. D Beaver could also be used for the same purpose as MongoDB Compass.
