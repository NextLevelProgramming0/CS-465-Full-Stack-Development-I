# CS-465-Full-Stack-Development-I

1) You have completed a full stack web application and added some login security features. In what ways does this make the site more secure, and what are the potential issues with only adding one layer of security? Consider why automated testing is more difficult when security is present.

   A full-stack web application's security is greatly increased by incorporating login security features like authorization and authentication, which limit access to sensitive information and functionality.  However, depending only on one security layer, such as basic login, exposes users to possible risks such session hijacking, password cracking, and brute-force assaults.  It is difficult to automate the testing of security features because security procedures frequently call for human contact or specialized tools to replicate real-world usage scenarios. This makes automated testing more complex. 

3) Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).  Why did the backend use a NoSQL MongoDB database?

   The Angular-built SPA loaded a single HTML page with dynamically updated content via JavaScript, providing a more app-like experience than Express HTML, which used handlebars to create separate HTML pages for various routes with full page reloads on navigation.  Because of its adaptability and capacity to store unstructured data, the backend made use of a NoSQL MongoDB database, which made scalability and schema management easier.

5) Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. Explain your understanding of methods, endpoints, and security in a full stack application.

   Using a variety of techniques to request and retrieve data, APIs act as the link between the frontend and backend in full-stack applications.  Testing these APIs entails assessing their security, performance, functionality, and dependability; the authentication and authorization layers add complexity.  For API testing to be successful in a full-stack application, it is essential to comprehend methods, endpoints, and security protocols.
